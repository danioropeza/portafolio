# My Personal Website

Hello, my name is Daniel Oropeza and this is my website. Here you can find all my experience and knowledge in the software development industry. I invite you to see my projects, articles, videos and certificates that I have.

My website is custom designed and built from scratch, it is responsive and accessible. The technologies I used for its construction are: Gatsby, React, GraphQL, Styled Components and Netlify.

To set the environment locally, run the following commands:

1.- `npm install`

2.- `npm run build`

3.- `npm run start`

### Versions:

- NodeJS: 21.5.0
- NPM: 10.2.4
- React: 18.2.0
- Gatsby: 5.13.0
